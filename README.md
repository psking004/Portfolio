# Partha Sarathi Portfolio

A static portfolio built with plain HTML and CSS. It has no dependencies or build step.

## Run locally

Open `index.html` in a browser, or serve the project folder over HTTP:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy with GitHub Pages

In this repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. Once the deployment finishes, the site will be available at <https://psking004.github.io/Portfolio/>.
